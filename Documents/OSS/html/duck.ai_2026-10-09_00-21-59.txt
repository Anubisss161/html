When you commit with Git, the commit is stored **locally on your computer**, inside the hidden `.git` folder in your project directory. It does not automatically go online.

Typical workflow:

```bash
git add .
git commit -m "Create restaurant homepage"
```

Your files remain in the project folder, while Git stores the commit history in:

```text
your-project/
├── index.html
├── style.css
└── .git/
```

To see your commit:

```bash
git log --oneline
```

To put the project on GitHub or another remote service, create a repository there and connect it:

```bash
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
git branch -M main
git push -u origin main
```

After that, future commits can usually be uploaded with:

```bash
git push
```

You can check whether a remote is connected with:

```bash
git remote -v
```

If that command displays nothing, your commit is currently only on your computer.
